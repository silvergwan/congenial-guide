# 메일 준비 도구

기존 개인 조사에서 사용한 도구를 옮겼습니다. 후보 검증, 수신자별 .eml 생성, 로컬 발송 상태 조회만 합니다. 네트워크 요청이나 메일 발송·회신 수집 기능은 없습니다.

저장소 루트 README의 명령으로 예시 설정을 복사하고 실행합니다. 실제 설정 파일은 Git에서 제외됩니다. 예시는 .invalid 도메인을 사용합니다.

- 입력: campaign.json, prospects.json, ../../templates/host-email-v0.1.txt
- 결과: runtime/messages.json, runtime/outbox/, runtime/ledger.json, 발송준비.md
- 검증: 중복 이메일·운영자·ID, 출처 미확인, 헤더 삽입, 미치환 변수, 최대 20곳
- 상태: 준비만으로 sent로 바꾸지 않습니다. 실제 발송 확인 근거가 있을 때 별도로 기록해야 합니다.
- 재실행: 같은 조사번호와 내용의 발송 상태를 유지하며, 기존 내용의 해시가 달라지면 중단합니다.

신규 예시 조사와 기존 실제 조사를 섞지 않습니다. 기존 실제 기록의 로컬 복사본은 저장소 루트의 .private/first-wave/에 있습니다.

주의: prepare 출력의 prepared는 생성 수입니다. sent는 저장된 기록일 뿐 실시간 Gmail 결과가 아닙니다. 실제 메일 전송이 불명확하면 조사번호로 보낸편지함을 확인하기 전 재발송하지 않습니다.
