# 안부 웹 프로토타입

저장소 루트에서 `npm run dev` 실행 후 http://127.0.0.1:4173 을 연다. 별도 패키지 설치는 필요 없다.

- **호스트**: ‘확인하기’ → ‘확인 시작하기’ → 가상 연락 결과 기록
- **여행객**: 시연할 여행객 선택 → 안내 확인·시간 선택 → 신청
- **데모 시계**: 약속 시각에 응답 대기, 15분 뒤 확인 필요로 변경
- **컴포넌트**: 버튼·상태 배지·폰트·색상·목록·시트 샘플
- **초기화**: 전체 가상 상태 초기화. 새로고침도 동일하게 초기화

‘이서준’으로 호스트 확인을 시작한 뒤 여행객 화면에서 ‘괜찮아요’를 누르면 늦은 응답과 연락 기록 보존을 시연할 수 있다. ‘김하늘’은 미신청 상태에서 시작한다.

실제 계정, 연락처, 메일·문자 전송, 위치 수집은 사용하지 않는다. `npm test`는 상태 전환과 기존 메일 준비 도구를 함께 검사한다.

디자인 의도와 참고 출처는 [디자인 시스템 v0.1](../docs/design-system-v0.1.md)에 있다.
