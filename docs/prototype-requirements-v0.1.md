# 프로토타입 요구사항 v0.1

상태: 구현 전 · 목적: 선택형 안부 확인 흐름의 이해도와 운영 가능성 검증

## 데모 구성

가상 숙소 1곳, 게스트 3명, 담당자 1명. 정상 응답, 미응답, 늦은 응답을 시연한다. 모든 화면에 데모임을 표시하며 실제 알림·전화·위치 전송은 일어나지 않는다.

사용자에게는 '입실 확인'과 '안부 확인'을 구분해 설명한다. 안부 응답은 실제 위치·입실·건강 상태를 증명하지 않는다.

## 화면

| 화면 | 필요한 정보·행동 |
|---|---|
| 여행객 신청 | 자발적 신청, 확인 날짜·시각, 담당자와 대응 가능 시간, 공유 정보·후속 절차 안내 |
| 여행객 응답 | 괜찮아요, 시간 변경, 신청 취소, 현재 상태와 다음 단계 |
| 호스트 목록 | 게스트 표시명, 약속 시각, 상태, 미응답 건, 담당자 |
| 호스트 상세 | 최근 상태, 연락 시도 기록, 담당자 확인 시작, 확인 완료·사유 |
| 데모 조작 | 시간 앞으로 이동, 게스트 역할 전환, 초기화 |

목록은 '확인 필요'로 표시하며 '위험 감지'·'사고 발생'이라고 표현하지 않는다. 실제 대응 범위가 정해지기 전에는 '24시간 보호'나 구조 보장을 약속하지 않는다.

## 상태 전환

| 상태 | 진입 조건 | 가능한 다음 상태 |
|---|---|---|
| 미신청 | 초기 상태 | 신청됨 |
| 신청됨 | 안내 확인 후 날짜·시각 선택 | 응답 대기, 취소됨 |
| 응답 대기 | 약속 시각 도달, 데모 확인 요청 표시 | 응답 완료, 확인 필요, 신청됨(시각 변경), 취소됨 |
| 확인 필요 | 약속 시각 + 유예시간까지 응답 없음 | 담당자 확인 중, 응답 완료(늦은 응답), 취소됨 |
| 담당자 확인 중 | 호스트가 확인 시작 | 담당자 확인 완료, 응답 완료(늦은 응답), 취소됨 |
| 응답 완료 | 여행객이 괜찮아요 선택 | 종료 |
| 담당자 확인 완료 | 호스트가 연락 결과·확인 근거를 기록 | 종료 |
| 취소됨 | 여행객 철회 | 종료 |

'응답 완료'는 자기보고 완료를 뜻한다. 호스트가 연락 실패를 '확인 완료'로 종료할 수 없고, 해결되지 않은 건은 확인 중으로 남긴다. 종료 후 다시 신청하면 별도 확인 건을 만든다.

## 시간·알림 정책

- 데모 표준시: Asia/Seoul. 날짜와 시각을 함께 표시한다.
- 시연용 유예시간: 15분. 변경 가능하며 실제 운영 정책은 인터뷰 후 결정한다.
- 데모의 시간 이동은 모의 시계만 변경한다.
- 취소·시각 변경 즉시 이전 예약 알림과 미응답 계산을 무효화한다.
- 중복 클릭·재진입으로 같은 확인 건이나 연락 필요 알림이 중복 생성되지 않는다.
- 담당자 확인 중 늦은 응답이 오면 목록과 상세를 갱신하고, 담당자의 진행 중 연락 기록을 보존한다.
- 화면 상태를 유지할 저장 방식은 구현 단계에서 결정한다. 실제 고객 데이터는 사용하지 않는다.

## 안내·정보 범위

신청 전에 게스트 표시명, 약속 시각, 응답 여부, 담당자 조치 기록을 누가 보는지 안내한다. 위치 정보·객실 영상·연락처는 이 데모에서 수집하지 않는다. 취소 시 이후 확인 요청을 중단하고 기록 처리 범위를 설명한다. 실제 서비스의 보관·삭제 정책은 미정이다.

## 완료 기준

- 정상 응답: 호스트에게 확인 필요 건이 생성되지 않는다.
- 미응답: 유예시간 전에는 확인 필요로 바뀌지 않으며, 경과 후 한 건만 생성된다.
- 시각 변경·취소: 이전 시각의 알림이 발생하지 않는다.
- 늦은 응답: 진행 중인 건이 업데이트되고 연락 이력이 사라지지 않는다.
- 호스트 확인: 담당자가 연락 결과를 남기고 근거와 함께 종료할 수 있다.
- 실패·미해결: 연락 실패를 안전 확인으로 표시하지 않는다.
- 초기화: 가상 상태와 조치 기록을 초기 상태로 되돌린다.
- 데모 버튼으로 실제 문자·메일·전화·신고가 실행되지 않는다.

## 사용자 검증 과제

여행객: 안부 확인 신청 → 담당자·공유 범위 설명 → 시각 변경 → 취소 또는 응답.
호스트: 확인 필요 게스트 찾기 → 연락 시도 기록 → 늦은 응답 확인 → 종료 판단.

과제 완료 여부, 혼동한 문구, 기대한 대응, 감시 느낌, 불필요한 연락을 기록한다. 클릭 수만으로 안전 효과나 시장성을 판단하지 않는다.
