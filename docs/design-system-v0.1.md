# 안부 디자인 시스템 v0.1

상태: 브라우저에서 실행 가능한 독립 구현 · 2026-11-03

## 방향

사용자가 요청한 TDS 구성 패턴을 참고해 선택형 안부 확인에 맞춘 컴포넌트를 직접 구현했다. 핵심 행동을 파란 버튼으로 강조하고, 읽는 순서와 여백으로 정보 위계를 만든다. 폰트는 Pretendard Variable 1.3.9를 로컬에서 제공한다.

공식 TDS UI Kit·패키지·아이콘·브랜드 자산은 포함하지 않는다. 토스나 바카티오의 공식 서비스가 아닌 개인 프로젝트다.

## 화면과 컴포넌트

| 화면 | 구성 | 시연 동작 |
|---|---|---|
| 호스트 | Navigation, 상태 안내, 현황 숫자, Tab, ListRow, Badge | 상태 필터, 상세 시트, 연락 시도, 근거와 함께 종료 |
| 여행객 | Top, 날짜 입력, 동의 Checkbox, 정보 공개, Bottom CTA | 신청, 시간 변경, 응답, 취소 |
| 컴포넌트 | 버튼·배지·타입·색상·목록·CTA/시트 샘플 | 버튼 피드백과 실제 화면 진입 |
| 공통 | 데모 시계, 초기화, Toast, Dialog | +15분/+1시간, 전체 초기화 |

`prototype/app.mjs`에서 버튼·배지·아이콘·시트 렌더링 함수를 공유한다. `prototype/styles.css`에 색상 토큰과 반응형 스타일, `prototype/state.mjs`에 화면과 독립된 상태 전환을 둔다.

## 스타일

| 항목 | 기준 |
|---|---|
| Primary | #3182f6 |
| 본문 | #191f28 |
| 보조 텍스트 | #6b7684 |
| 바탕 | #f7f8fa / #f2f4f6 / white |
| 확인 필요 | 주황색 + ‘확인 필요’ |
| 응답·확인 완료 | 초록색 + 완료 문구 + 체크 |
| 폰트 | Pretendard Variable, 주로 400/500/600/700 |
| 버튼 | 기본 높이 48px, 작은 버튼도 터치 영역 최소 44px |
| 모서리 | 버튼 12px, 패널 20px, 시트 24px |
| 배치 | 최대 폭 1200px, 760px 이하 한 열, 모바일 시트는 하단 배치 |

상태는 색만으로 구분하지 않는다. 포커스 테두리, 기본 폼 라벨, 키보드로 닫을 수 있는 네이티브 dialog, 움직임 줄이기 설정을 지원한다.

## 데모 정책

- 가상 여행객 3명과 가상 담당자 1명. 서버 전송·영구 저장·실제 연락은 없다.
- 상태는 현재 브라우저 탭 메모리에만 둔다. 새로고침하면 초기화된다.
- 모의 시계는 한국 시간 2026-11-03 20:10부터 시작한다.
- 미응답 유예시간 15분. 담당 시간 18:00–23:00에 맞춰 신청 시간은 18:00–22:45로 제한한다. 이 시간은 시연 가정이며 실제 정책은 인터뷰 후 결정한다.
- 새 확인 건을 신청할 때 이전 기록은 메모리 안에 보존한다. 과거 확인 건을 조회하는 화면은 이번 범위에 포함하지 않는다.
- 안부 응답은 자기보고다. 입실·실제 위치·안전 상태를 판정하지 않는다.

## 실행과 확인

```powershell
npm run dev
npm test
```

미리보기: http://127.0.0.1:4173

서버는 `prototype/`의 공개 화면 파일만 허용 목록으로 제공한다. 저장소 루트, 조사 원문과 `.private/`는 제공하지 않는다. 런타임 패키지 설치 없이 Node.js 22 이상에서 실행한다.

브라우저로 데스크톱과 390px 모바일 화면을 확인했다. Pretendard 로드, 신청, 시간 변경, 취소, 담당자 확인, 연락 실패, 늦은 응답 이후 기록 보존을 확인했다. 자동 검사는 시간 경계·취소·중복 요청·기록 보존·근거 없는 종료 방지 등을 검증한다.
