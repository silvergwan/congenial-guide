# 조사 진행 현황

기록일: 2026-11-03. 이 문서는 당시 확인한 결과이며 실시간 Gmail 상태를 반영하지 않는다.

| 항목 | 확인 상태 |
|---|---|
| 1차 조사번호 | JEJU-20261103 |
| 메일 내용 | 독채 운영자 대상 질문 6개, 개인 프로젝트 명시 |
| 비교 기간 | 2026년 9~10월 투숙 / 2025년 9~10월 투숙 |
| 발송 | Gmail에서 20통 개별 발송 및 보낸편지함 확인 |
| 반송 | 당시 1건 확인: 수신 주소 없음 |
| 그 외 19건 | 발송 확인, 수신·열람 여부 미확인 |
| 설문 회신 | 이 문서 작성 시점에 최신 수신함을 재조회하지 않음 |
| 2차 후보 | 5곳 검토, 이메일 확보 0곳, 추가 발송 없음 |
| 자동화 | 메일 생성·검증 도구 있음. 자동 발송·수집·주기 확인 미설정 |
| 프로토타입 | 요구사항만 작성, 화면 구현 전 |

발송 수는 전달 성공 수나 응답 수가 아니다. 향후 회신율을 계산할 때 분모가 전체 발송인지, 확인된 반송을 제외한 연락 대상인지 명시한다.

수신자별 원본·증빙은 로컬 `.private/first-wave/`에 보관하며 공개하지 않는다. 실제 회신 분석은 [분석 기준](reply-coding-guide.md)을 따른다.
