# 회신 분석 기준 v0.1

## 분석 단위

운영자 1명을 기본 단위로 하고 숙소·객실 유형을 별도 기록한다. 독채와 호텔, 실제 1인 투숙 경험 유무를 분리한다. 여러 답변을 보낸 동일 운영자를 중복 집계하지 않는다.

## 기록 항목

| 항목 | 값·기록 방식 |
|---|---|
| 응답 ID | 공개용 가명 ID. 이메일·실제 숙소명과의 연결표는 로컬 보관 |
| 질문 버전·수신일 | v0.1/v0.2, 날짜 |
| 숙소 유형·지역 | 독채/호텔/혼합/불명, 필요 최소 지역 |
| 1인 투숙 허용·경험 | 예/아니오/불명. 허용과 실제 경험을 구분 |
| 예약 변화 | 전체와 1인 각각 증가/비슷/감소/비교불가/무응답 |
| 비교 기간 | 응답자가 실제 비교한 기간 |
| 판단 근거 | 예약 기록/체감/불명 |
| 안전 문의 | 있음/없음/알 수 없음/미답변 |
| 안전 이유 취소·변경 | 직접 들은 사례/운영자 추정/없음/불명 |
| 그 외 요인 | 가격·교통·계절·마케팅 등 응답에 나온 내용만 기록 |
| 현재 확인 절차 | 계기 → 담당자 → 행동 → 종료 기준 |
| 부담 | 실제 사례·시간·빈도. 수치가 없으면 임의 생성하지 않음 |
| 연락 의사 | 추가 연락 가능/거절/미확인 |
| 검토 상태 | 원문 대조 전/대조 완료 |

## 근거 원칙

각 해석에 원문 위치나 로컬 메시지 참조를 연결한다. 응답자의 직접 경험과 분석자의 추론을 분리하고 반례도 기록한다. 모순·불명확한 답은 그대로 남기고 필요하면 후속 질문 후보로 만든다.

'없음', '알 수 없음', '미답변', '반송'을 서로 다른 값으로 다룬다. 무응답을 부정 응답으로 코딩하지 않는다. AI 자동 추출을 도입하더라도 원문 대조 전 결과는 초안이며 현재 자동 추출기는 구현되지 않았다.

## 공개 결과

표본 수·유효 응답 수·분모·질문 버전·응답 시점을 명시한다. 작은 표본의 비율보다 구체적 문제와 반례를 우선 서술한다. 연락처와 숙소를 알아볼 수 있는 사례 세부사항은 공개하지 않는다. 안전 보도와 예약 변화의 인과관계, 서비스 효과를 단정하지 않는다.
